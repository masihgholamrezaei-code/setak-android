# اپ اندروید «تعمیرات ستاک»

اپ بومی (Kotlin + Jetpack Compose) برای کارمندان و تکنسین‌ها. با افزونه‌ی «مدیریت تعمیرات ستاک» نسخه ۰٫۵ به بالا کار می‌کند.

## امکانات
- ورود با Application Password وردپرس (رمز در حافظه‌ی رمزنگاری‌شده‌ی گوشی)
- داشبورد، «نیازمند توجه»، منتظرها و ماندگارها
- لیست پرونده‌ها با جستجو، فیلتر وضعیت و صفحه‌بندی
- جزئیات پرونده، تماس و پیامک به مشتری، تغییر وضعیت (با پیام آماده و دلیل)، ویرایش تشخیص
- پذیرش جدید با پیشنهاد برند و تشخیص مشتری قبلی
- اسکن QR برچسب دستگاه یا رسید (بدون نیاز به سرویس‌های گوگل)
- اعلان وقتی مشتری هزینه را تأیید/رد کند یا امتیاز بدهد (بررسی هر حدود ۱۵ دقیقه، بدون FCM)

## ساخت (Build)
۱. Android Studio (Koala یا جدیدتر) با JDK 17. پوشه‌ی پروژه را باز کنید و منتظر Gradle Sync بمانید (اینترنت لازم است).
۲. گوشی را وصل کنید یا شبیه‌ساز، Run.
۳. برای APK: Build ← Build Bundle(s)/APK(s) ← Build APK(s). برای انتشار، APK را امضا کنید (Build ← Generate Signed Bundle/APK).

**توجه:** این پروژه خارج از Android Studio نوشته شده و من آن را کامپایل نکرده‌ام. اگر هنگام Sync یا Build خطایی دیدید، متن کامل خطا را بفرستید تا اصلاح کنم.

## تنظیم سمت سایت
- افزونه ۰٫۵ را نصب کنید، سایت باید HTTPS باشد و پیوند یکتای وردپرس روی «ساده» نباشد.
- در پروفایل کاربر وردپرس (ترجیحاً کاربر با نقش مدیر تعمیرات/تکنسین)، یک Application Password بسازید و در اپ همان را وارد کنید.
- اگر ورود ۴۰۱ داد، بخش «هدر Authorization» فایل `docs/API.md` افزونه را ببینید.

## نکات
- گوشی‌های برخی برندها پردازش پس‌زمینه را محدود می‌کنند؛ برای اعلان، بهینه‌سازی باتری اپ را خاموش کنید.
- اگر گوشی گم شد، Application Password همان گوشی را از پروفایل وردپرس حذف کنید.
- فونت وزیر (OFL) همراه اپ است؛ مجوز آن را همراه فونت نگه دارید.
